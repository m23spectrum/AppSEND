# AppSEND — Android 1.6 / Windows 1.6 — быстрый старт

## Готовые приложения

1. На Windows запустите `binaries/AppSEND-Windows-x64-Setup.exe` и установите AppSEND.
2. На Android установите `binaries/AppSEND-Android-debug.apk`. При необходимости Android предложит разрешить установку APK для приложения, из которого вы открыли файл.
3. Подключите устройства к одной локальной сети и откройте AppSEND на обоих. В Windows разрешите приложению доступ через брандмауэр для частной сети. На Android запрос разрешения уведомлений больше не показывается.
4. Выберите устройство в списке. Выберите файл или нажмите «Вставить текст или ссылку».
5. Нажмите «Отправить». Входящий файл принимается автоматически: без запроса, всплывающего окна и отдельного уведомления.

На Windows полученные файлы сохраняются в `Downloads/AppSEND` и доступны в «Полученных файлах». На Android полученные файлы доступны во вкладке «История»; действия открытия и сохранения открывают системный выбор приложения.

Установщик Windows пока без подписи издателя. Android APK является отладочной сборкой. Производственная квалификация датчиков, FPS и работы на разных реальных устройствах ещё не выполнена; подробности находятся в `VALIDATION.md`.

## Язык и способы передачи

При первом запуске выберите Русский или English. Выбор сохраняется; кнопка RU/EN на Windows и настройки на Android позволяют его поменять.

На Android выберите один из трёх способов:

- **Захват (телефон → ПК):** выберите файл и ПК, нажмите «Захват» → «Отправить». Сожмите кулак перед камерой, затем раскройте ладонь — файл отправится сразу после распознавания. Руку можно держать в центре кадра. Выход через край кадра тоже работает как дополнительный способ. Кнопка «Отменить захват» сбрасывает жест. Камера работает только на телефоне и не вычисляет расположение монитора. Подробнее: `ЗАХВАТ.md`.
- **Бросок:** выберите файл и устройство, затем нажмите «Отправить». Откроется отдельный экран. Смахните его карточку вверх и отпустите: файл улетит с телефона и появится на ПК. Само открытие экрана ничего не отправляет. После доставки нажмите «Готово».
- **Через край:** держите телефон над верхней рамкой монитора. Направьте верхний торец или экран телефона вниз к рамке, поднесите датчик приближения близко. Достаточно перевёрнутого положения около 200 мс. Движение, скорость и остановка не анализируются: поднимать телефон или делать взмах не нужно. Обычное вертикальное положение экраном вверх этот режим не запускает. Если датчик у рамки не отвечает, остаётся ручное удержание полоски внизу экрана.

На Windows подготовьте файл и выберите устройство. Нажмите «Отправить» или включите «Через край»: подержите курсор у верхней границы 700 мс либо перетащите файл на полосу края.

Получатель по умолчанию принимает файл автоматически. После согласования начинается анимация: файл сначала исчезает у отправителя, затем появляется у получателя. «Через край» связывает верх экрана телефона с верхом монитора: при перевёрнутом телефоне эти края обращены друг к другу. Светлая волна вытягивается от края и раскрывает карточку. «Бросок» приземляет карточку файла на ПК.

Имя устройства не подтверждает его личность. При автоприёме другие устройства LAN могут записывать файлы в папку приёма; используйте знакомую сеть. В настройках можно отключить «Принимать автоматически». Файлы и ссылки сами не открываются.

Уведомления о поступлении файла и окна приёма отсутствуют. Android требует служебную запись для фоновой работы: она тихая, без имени файла и обновлений при каждой передаче. Программа не запрашивает разрешение POST_NOTIFICATIONS.

Если рядом только одно устройство, Android выбирает его автоматически. Когда устройств несколько, выберите нужное вручную. Датчик замечает близкий предмет, но не определяет, какой именно компьютер перед ним.

Чтобы получить подготовленный на компьютере файл, уберите локальный файл крестиком, во вкладке «Получить» выберите компьютер и нажмите «Забрать подготовленный файл» либо используйте нижнюю зону удержания. Компьютер запросит разрешение владельца отправить файл.

## Сборка из исходников

### Windows

Установите Node.js 22.12+ и выполните из папки проекта:

```powershell
cd desktop
npm ci
npm start
```

Если политика npm отключила установочный скрипт Electron, выполните `node node_modules/electron/install.js`, затем повторите `npm start`.

Тесты: `npm test`. Установщик: `npm run dist`, результат появится в `desktop/dist`.

### Android

Откройте папку `android` в Android Studio. Используйте JDK 17 и установите SDK Platform 35, Build Tools 35.0.0 и platform-tools. Дождитесь синхронизации Gradle и нажмите Run с подключённым устройством.

Из терминала в папке `android`, если `JAVA_HOME` и `ANDROID_HOME` указывают на ваши установленные инструменты:

```powershell
.\gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для тестов Kotlin сначала выполните `npm ci` в соседней папке `desktop` и убедитесь, что `node` доступен в PATH, затем:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug
```

Поддерживается Android 8.0/API 26 и новее. Подробное устройство проекта, список зависимостей и инструкции выпуска находятся в `README.md`; сетевой формат — в `PROTOCOL.md`; визуальные решения и разбор референсов — в `DESIGN.md`.
