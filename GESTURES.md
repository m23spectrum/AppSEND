# Захват рукой: AppSEND 1.6, Android → Windows

Выберите файл и свой ПК в «Устройства рядом», затем метод «Захват» → «Отправить». Разрешите камеру при первом использовании.

1. Сожмите кулак перед фронтальной камерой — карточка файла сожмётся и появится тактильный отклик.
2. Когда подсказка сменится на «Раскройте ладонь», откройте руку. Файл улетит на ПК.

Рука может оставаться в центре кадра. Показывать открытую ладонь перед первым кулаком не требуется. Как дополнительный способ можно увести захваченную руку через край кадра. Простое исчезновение руки в центре не отправляет файл.

«Отменить захват» сбрасывает жест без перезапуска камеры. После отмены раскройте руку и начните новый захват; удерживаемый кулак не захватывается повторно сам. Пауза приложения, ошибка камеры, потеря руки в центре кадра более 260 мс или истечение 6 секунд отменяют захват. Изменение файла или получателя отменяет отправку.

ПК определяется выбранным LAN-устройством. Приложение не вычисляет физическое положение монитора. USB служит для установки и отладки; файлы передаются по локальной сети. Камера ПК не требуется.

Камера работает только на открытом экране «Захват» в активном приложении. Кадры остаются в памяти телефона, не записываются и не передаются. Модель включена в APK. Изображение камеры цветное, без фильтра; монохромная палитра относится только к интерфейсу. При запрете доступа разрешите камеру в настройках Android и откройте режим заново.

На ПК включённый «Автоматический приём» сохраняет файл без запроса. Файл не открывается сам. После начала передачи камера освобождается; виден прогресс, затем анимация доставки.

## Реализация и задержки

CameraX 1.4.2: фронтальная камера, PreviewView FIT_CENTER, анализ полного повёрнутого кадра, один рабочий поток и только последний доступный кадр. Прежний искусственный интервал между анализами убран; фактическая частота зависит от камеры и времени обработки. MediaPipe Tasks Vision 0.10.32 работает локально в VIDEO-режиме.

Кулак с уверенностью ≥0.60 не менее 70 мс → захват → раскрытая ладонь с уверенностью ≥0.60 не менее 45 мс → однократная отправка. Один ошибочно распознанный кадр ладони не считается завершённым жестом. Для дополнительного выхода из кадра проверяются крайние 27% и отсутствие руки не менее 100 мс. Остановка обработки более 500 мс сбрасывает состояние. Ошибка или отсутствие кадров не считаются жестом.

Для немедленного вылета запас синхронизации составляет max(250 мс, 3 × минимальный RTT + 180 мс). Это настроенные пороги, а не измеренная гарантия полной задержки. На проводе используется существующая анимация plane. Windows 1.4 совместима с передачей, но чёрно-белый интерфейс и оверлей поставляются в Windows 1.6.
